# 🌍 Aventura das Letras: Mundo Aberto

Um jogo educativo com mecânicas de mundo aberto (estilo Pokémon/GTA), focado no desenvolvimento da **leitura, interpretação de texto e lógica** para crianças. Tudo de forma divertida, exploratória e sem infantilizar o desafio!

🕹️ **[JOGUE AGORA (Clique Aqui)](https://seu-usuario.github.io/letras-abertas/)**

## ✨ O que este projeto resolve?
Jogos educativos tradicionais costumam ser monótonos (clicar em respostas em uma tela parada). Este jogo aplica o conceito de **"Game Feel" e Mundo Aberto**:
* **Exploração Livre:** A criança decide para onde vai e com quem fala.
* **Mecânica de Veículos:** Ao clicar em "SKATE", o jogador dobra de velocidade (recompensa motora, estilo *GTA*).
* **Interação Real:** Entrar em lojas, conversar com NPCs.
* **Desafio Intelectual:** A leitura é necessária para ganhar moedas e evoluir, unindo a recompensa clássica de RPG com a alfabetização e interpretação de texto.

## 🛠️ Tecnologias Utilizadas
* **HTML5 / JavaScript Nativo**
* **Phaser 3:** Uma das engines web mais poderosas.
* **Gráficos Procedurais:** Sem necessidade de carregar imagens (tudo desenhado via código), garantindo que o jogo rode de forma **imediata** até em conexões 3G.

## 📱 Controles Otimizados
* **No Computador:** Setas do teclado ou WASD para andar, e mouse para clicar no skate/opções.
* **No Celular:** Toque em qualquer lugar da tela e o personagem andará até aquele ponto (Tap-to-move estilo mobile RPG).
